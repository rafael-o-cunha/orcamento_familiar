# notas

Anotações do desenvolvedor durante o projeto: o que aprendeu, dúvidas, decisões, erros e como resolveu. Não precisa ser formal.

## Como organizar

- Um arquivo por dia ou por assunto: `AAAA-MM-DD-assunto.md` (ex.: `2026-11-03-paginacao-lazy.md`).
- Cite a issue quando a nota for de uma tarefa (ex.: `#12`).
- Dúvidas abertas ficam com `**Dúvida:**` no começo da linha, para levar à daily.

## Modelo

```markdown
# 2026-11-03 — Paginação lazy (#12)

## O que fiz

## O que aprendi

## Dúvida:

## Links úteis
```
